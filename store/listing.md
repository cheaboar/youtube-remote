### 简短说明（≤132 字符）

用方向键或蓝牙遥控器在 YouTube、抖音、B站、优酷选片与播放；双击打开指令面板，三击进入浏览器全局遥控。

### 详细说明

```
用蓝牙遥控器或键盘，在电脑上像看电视一样选片。

支持的网站
• YouTube：首页、搜索、频道、Shorts、播放页
• 抖音：精选页、视频页、右侧推荐栏
• 哔哩哔哩：首页、视频页、右侧推荐
• 优酷：首页、播放页、选集

怎么用
• 方向键在视频卡片间移动，确认键播放
• 播放页 ↑↓ 调音量，←→ 快进后退 5 秒
• 双击 ↓ 进入右侧推荐栏继续选片
• 双击确认键打开播放页指令面板：播放/暂停、静音、全屏、网页全屏、弹幕开关、点赞、收藏、下一集、翻页等
• 三击确认键进入浏览器全局遥控：切换标签、后退/前进、打开菜单，在任何网页都能用（需你主动授权全站访问）
• 所有按键都可以在设置页重新录制；B站与优酷、抖音与 YouTube 各自保存一套组合键，互不冲突
• 附赠 Windows 小工具，可把遥控器按键转发成其他程序里的快捷键（需手动运行，可选）

隐私
• 不联网、不统计、不含广告和第三方 SDK
• 设置只保存在本机浏览器中
• 不读取页面文字、评论或账号信息，只识别选片和播放所需的页面结构

说明
• 遥控器本身需在系统里表现为键盘（蓝牙遥控器、键盘模式遥控器或软件遥控器均可）
• 浏览器全局模式需要可选的全站访问权限，授权可随时撤销
```

## 权限说明（提交时逐项填写）

- `storage`：保存按键映射、双击间隔、组合键、常用网站和 Windows 系统按键配置。
- `tabs`：浏览器全局模式需要读取标签页标题和图标以显示切换菜单，并在关闭最后一个标签前准备恢复页。
- `scripting`：设置变更后向已打开的页面补注入内容脚本，无需用户刷新。
- 站点权限 `youtube.com` / `douyin.com` / `bilibili.com` / `youku.com`：在这些网站提供方向键选片与播放控制。
- 可选权限 `http://*/*`、`https://*/*`：仅在用户主动点击「启用浏览器全局遥控」并确认授权后请求，用于在普通网页响应方向键、滚动和焦点移动；撤销后立即退出该模式。

## 单一用途说明

在视频网站上用键盘或蓝牙遥控器完成选片、播放和页面导航。

## 远程代码

未使用远程代码。所有脚本随安装包分发，不使用 `eval`、动态脚本注入或外部 CDN。

## 数据使用声明（Data usage）

- 是否收集用户数据：**否**
- 不收集个人身份信息、健康、财务、认证信息、个人通讯、位置、网页浏览记录、用户活动、网站内容。
- 不使用或转让数据给第三方，不用于确定信用度或贷款，不用于出售。
- 三项认证复选框均可勾选（数据未被出售、用途与披露一致、未违反相关限制）。

## 隐私政策 URL

需要可公开访问的地址，提交前请自行托管 `store/privacy.html`，然后把地址填入开发者后台。例如放在任意静态站、对象存储或自己的域名下，路径可以是 `/privacy.html`。

## 提交流程

1. 打开 https://chrome.google.com/webstore/devconsole （需一次性支付 5 美元注册开发者账号，个人账号约 1–2 天审核身份）。
2. 「新增项目」→ 上传 `dist/youtube-remote-2.0.0.zip`。
3. 填写上面的名称、简短说明、详细说明、类别、语言。
4. 「隐私权」页填写单一用途、权限理由、远程代码选「否」，勾选数据使用声明，填入隐私政策 URL。
5. 上传商店图标、4 张截图、小型与大型宣传图。
6. 「分发」选择公开、所有地区，填写联系邮箱。
7. 提交审核。首次审核通常 1–3 个工作日；含 `tabs` 与可选全站权限，可能被要求补充说明，按上面的权限理由填写即可。

播放器与 Shorts 中的双击操作

只在播放器区域识别双击，列表中连续方向键始终用于移动。Shorts 中双击 → / ← / ↑ 分别展开评论、关闭评论和点赞；与双击共用的方向键单击时会等待双击间隔后再切换或快进，避免双击前先跳走。普通视频页第一次按键立即执行，可能改变一次音量。

复合键模式

单击确认会等待双击间隔后执行。面板打开后，↑↓ 选择指令，Return / Enter 或确认键立即执行；← / → 开始输入组合，之后方向键继续组合，匹配完成立即执行。Esc 或返回键退出，Backspace 撤销。新组合以 ← 或 → 开头，共 2–4 步；清空只禁用组合，仍可从菜单选择，不允许重复或互为前缀。已有自定义组合保留。

抖音播放页组合键

抖音播放页的指令面板单独使用一套组合键：按 ← 或 → 开始输入，列表只保留以已输入按键开头的指令（最左匹配），输入到完整组合立即执行，Backspace 撤销一步。与 YouTube 的组合键分开保存，互不影响。

B站播放页组合键

哔哩哔哩播放页单独使用一套组合键：按 ← 或 → 开始输入，列表只保留以已输入按键开头的指令（最左匹配），输入到完整组合立即执行，Backspace 撤销一步。与 YouTube、抖音的组合键分开保存，互不影响。

优酷播放页组合键

优酷播放页同样单独使用一套组合键，规则与 B站一致；B站与优酷可以各用各的按键序列，互不冲突。优酷页面没有点赞、收藏等控件时，面板不会列出这些指令。

浏览器全局模式

正在检查授权…

双击「浏览器模式」键（默认 Enter）进入；YouTube 页内和各网站的播放页（抖音视频页、B站视频页、优酷播放页）需三击，因为双击已用于复合键／指令面板。直控时 ↑↓ 切换标签页，←→ 后退／前进，确认打开菜单，返回退出。菜单内 ←→ 切换「常用／网站／标签／页面」，↑↓ 选择，确认执行，返回直控。滚动、输入框选择、网页焦点和关闭均可只用方向、确认和返回键操作，无需键盘。

要在 YouTube 以外的网页继续遥控，需要授权扩展访问网站。授权只用于注入遥控脚本，不读取本地文件；地址栏、浏览器内部页和应用商店无法接收按键。模式所在标签页跳到这些页面时，扩展转到同窗口可用网页；没有候选时使用本地恢复页。焦点在地址栏或操作系统界面时扩展无法接收按键。

Windows 软件快捷键

需要运行本机助手

浏览器扩展不能向其他软件发送按键。保存映射后下载 remote-keys.json，放进扩展目录的 native 文件夹，运行 start-remote-keys.cmd（或隐藏启动的 start-remote-keys-hidden.vbs）。助手在前台软件匹配时拦截遥控按键并转发为下面的目标快捷键；其他按键和未匹配的软件原样通过。它不联网，也不记录输入内容，只写已触发映射的日志。

进程名可在任务管理器的「详细信息」里查看（例如 PotPlayerMini64.exe、vlc.exe、POWERPNT.EXE）。窗口标题包含项可选，用于区分同一软件的不同窗口；进程名和标题都留空表示全局匹配（最多一个）。遥控键必须是单个按键，不能带 Ctrl / Alt / Shift；目标快捷键可以带修饰键，也可直接填写。

「添加抖音电脑版」会创建匹配 douyin.exe 的配置：确认键→空格（播放/暂停）、Home→Z（点赞）、PageUp/PageDown→上/下一条视频。抖音客户端可在「快捷键设置」中查看或修改自己的键位；若不一致，直接改这里的「目标快捷键」。在评论框里按确认也会被转发成空格，需要输入文字时可按助手托盘菜单暂停映射。

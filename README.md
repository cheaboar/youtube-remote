# YouTube / 抖音 / B站 / 优酷 蓝牙遥控选片

Chrome / Edge Manifest V3 扩展。用蓝牙遥控器或键盘在 YouTube、抖音、哔哩哔哩和优酷网页完成选片、语音文字搜索、播放和返回，无需构建。

项目仓库：[cheaboar/youtube-remote](https://github.com/cheaboar/youtube-remote)。

## 功能

- **方向键选片**：上下切换节目行，左右选择同一行的视频，蓝色光晕标出当前位置；滑到列表末尾时触发更多节目加载。
- **抖音网页选片**：在 `douyin.com/jingxuan` 用方向键选择精选视频，确认键在当前标签页打开；视频页支持快进、播放暂停、右侧推荐栏选片，并可双击确认打开播放页指令面板，返回后回到上次选择的位置。
- **B站 / 优酷网页选片**：B站首页、视频页和优酷首页、播放页使用同一套遥控语法：方向键选片，播放页 ↑↓ 调音量、←→ 快进退，双击 ↓ 进入右侧推荐栏，双击确认打开播放页指令面板；B站与优酷各自保存一套组合键，互不冲突。
- **左侧导航**：首页节目行最左侧再按 ← 进入导航栏，↑↓ 选择首页、Shorts、订阅等入口，Return / Enter 打开，→ 或 Esc 回到原节目；支持展开栏和迷你栏，并可用 Alt+Shift+N 或复合键随时展开／收起。
- **复合面板**：双击 Return / Enter 打开，↑↓ 选择并确认执行，也可依次输入以 ← / → 开头的组合；指令按常用、播放器、页面分类。
- **浏览器全局模式**：双击 Enter 进入（YouTube 页内和抖音 / B站 / 优酷的播放页三击），↑↓ 切换标签页、←→ 后退／前进，确认打开菜单，返回退出。菜单分常用、网站、标签、页面四组；授权可选的全站权限后，在普通网页同样可用。
- **谷歌搜索**：浏览器模式的常用组有「谷歌搜索」，在面板输入框里直接输入或语音输入关键词，确认后在当前标签页打开搜索结果；搜索结果页双击 → 开始筛选，↑↓ 选择结果、←→ 翻页、确认打开、Esc 取消筛选。
- **网页操作与恢复**：仅用方向、确认、返回键即可滚动、选择输入框、访问收藏网站及恢复本扩展关闭的网页。关闭标签页需要二次确认。
- **播放器控制**：播放暂停、静音、字幕、全屏、影院模式和原生播放器设置。
- **画中画看评论**：播放页一键开启系统画中画并定位到评论区，↑↓ 滚动评论、←→ 翻页；恢复键退出画中画并回到播放器顶部，另有「回到页面顶部」指令。
- **Shorts 双击操作**：双击 → 展开评论并把焦点放到评论列表，↑↓ 连续翻看；双击 ← 关闭评论；双击 ↑ 点赞。为避免点赞前先切到上一条，与双击共用的方向键会先等待双击间隔再执行原来的切换或快进。
- **搜索与返回**：定位搜索框接收遥控器语音文字，逐层退出搜索、侧栏、全屏；从播放页返回后恢复节目选择。
- **Liquid Glass 界面**：磨砂透明面板、灰色文字、蓝色选中项和平滑滑动高亮；全屏时隐藏右下角提示，复合面板仍可打开。
- **遥控器配置**：录制单键、修饰键组合、双击和按键序列，支持冲突检查与按键诊断。
- **Windows 软件映射（可选）**：附带的 PowerShell 本机助手按前台软件把遥控按键转发为其他程序的快捷键，适合 PotPlayer / VLC、PowerPoint / WPS 演示、音乐软件和抖音电脑版；在设置页编辑映射并导出 `remote-keys.json`。

## 安装或更新

先在 GitHub 选择 **Code → Download ZIP** 并解压，或使用 Git 下载：

```sh
git clone https://github.com/cheaboar/youtube-remote.git
cd youtube-remote
```

1. 打开 `chrome://extensions` 或 `edge://extensions`，启用「开发者模式」。
2. 首次安装选择「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目目录。
3. 刷新已打开的 YouTube、抖音、B站或优酷页面，确保旧版内容脚本已被替换。
4. 点击扩展图标 →「配置遥控器与按键诊断」，录制遥控器按键并保存。

日常使用无需运行 `npm install` 或启动开发服务器。更新时下载最新代码覆盖原目录，或在项目目录执行 `git pull --ff-only`；然后在扩展管理页点击「重新加载」，再刷新 YouTube。已有按键配置会保留。

## 快速上手

1. 在 YouTube 首页或搜索结果中用方向键选片，单击 Return / Enter 打开节目。
2. 播放时双击 Return / Enter 调出复合面板，用 ↑↓ 选中所需功能，再按 Return / Enter 执行。
3. 选择「定位搜索框」后，使用遥控器的语音输入，再按确认键搜索。
4. 按 Esc 逐层返回；退出视频全屏后，右下角的操作提示会恢复。看评论时可在复合面板选「画中画看评论」，按 Alt+Shift+R 或复合键「恢复正常播放」回到播放器。
5. 在首页按 ← 移动到节目行最左侧，再按一次 ← 选择左侧导航；也可用 Alt+Shift+G 或复合面板中的「左侧导航」进入。按 Alt+Shift+N 或在复合面板中选择「展开 / 收起左侧导航」，可只切换导航栏的展开状态而不进入导航选择。
6. 双击 Enter 进入浏览器全局模式（YouTube 页内和抖音 / B站 / 优酷的播放页三击），↑↓ 换标签、←→ 后退／前进，确认打开菜单，返回退出。普通网页需先授权全站访问。
7. 菜单中 ←→ 切组、↑↓ 选择、确认执行、返回直控；在网站组访问收藏，在常用组选择「谷歌搜索」输入关键词，或选择滚动、输入等操作。
8. 在谷歌搜索结果页双击 → 开始筛选，↑↓ 在自然结果间移动、←→ 翻页，确认打开，Esc 取消筛选（不改变页面）。
9. 在抖音精选页用方向键选片，单击确认打开视频；视频页确认键暂停／播放、←→ 快进后退，单次 ↑↓ 翻页，双击 ↓ 进入右侧推荐栏继续选片，双击确认键打开播放页指令面板（点赞、收藏、分享、网页全屏、上一条／下一条等），Esc 回到精选页并恢复上次位置。
10. 在 B站首页或优酷首页用方向键选片，确认打开视频；播放页 ↑↓ 调音量、←→ 快进后退、双击 ↓ 选右侧推荐、双击确认打开指令面板，Esc 逐层返回。B站面板含点赞、投币、收藏、分享和评论区；优酷页面没有这些控件时不会列出。

## 默认操作

| 按键 | 操作 |
| --- | --- |
| 方向键 | 节目列表选片；播放器左右调整 5 秒、上下调整 5% 音量；评论区上下滚动、左右翻页；搜索框保留编辑与建议选择 |
| Enter | 单击等待双击间隔后打开节目／播放暂停／提交搜索；双击进入复合键模式（抖音视频页为指令面板） |
| Esc | 清空并退出搜索；左侧导航返回原区域；右侧列表返回播放器；评论区恢复正常播放；全屏先退出全屏；其他情况返回上一页 |
| Alt+Shift+H | 返回 YouTube 首页 |
| Alt+Shift+S | 定位搜索框，选中原文字供语音替换 |
| Alt+Shift+G | 进入左侧导航，↑↓ 选择，→ 或 Esc 返回原区域 |
| Alt+Shift+N | 展开／收起左侧导航栏，不改变当前操作区域与选中节目 |
| Alt+Shift+Y | 进入右侧节目列表，优先播放列表，没有则使用相关推荐 |
| Alt+Shift+P | 回到播放器控制 |
| Alt+Shift+K | 播放／暂停 |
| Alt+Shift+F | 切换视频全屏 |
| Alt+Shift+R | 退出画中画看评论，恢复正常播放 |
| Alt+Shift+B | 直接返回上一页 |
| 双击 →（谷歌搜索结果页） | 开始筛选搜索结果：↑↓ 选择结果、←→ 翻页、确认打开、Esc 取消筛选 |
| 播放器中双击 ↓ / ↑ | 进入右侧列表／搜索框 |
| Shorts 中双击 → / ← | 展开评论并聚焦／关闭评论 |
| Shorts 中双击 ↑ | 点赞当前 Shorts，不切换视频 |
| 双击 Enter（YouTube 页内、抖音 / B站 / 优酷播放页三击） | 进入浏览器全局模式（入口键可重新录制），模式内键位见下文 |

双击间隔默认 400 毫秒，可调整。视频页第一次方向键立即执行，所以双击前可能改变一次音量；Shorts 中与双击共用的方向键会先等待双击间隔，再执行切换或快进，因此双击不会先跳到相邻视频。进入列表后连续方向键只移动选择。抖音视频页不接管音量：单次 ↑↓ 滚动页面内容，双击 ↓ 进入右侧推荐栏。**2.0 起 Esc 改为单次逐层返回，Alt+Shift+Y 改为进入侧栏；回到播放器使用 Esc 或 Alt+Shift+P。**画中画看评论后，Alt+Shift+R、Esc 或复合键「恢复正常播放」都会退出画中画并回到播放器。

macOS 键帽上的 Return 就是这里的 Enter；扩展兼容 `Return`、`Enter` 和小键盘 Enter，也会转换已录制的 Return 映射。

页面右下角显示当前操作区域，播放器提示「双击 Enter 调出复合面板」（跟随确认键配置）；Shorts 页会列出双击 →／←／↑ 的评论和点赞操作；评论打开后提示双击 ← 关闭、↑↓ 翻看。视频全屏时隐藏右下角提示，退出全屏后恢复。返回列表时恢复此前选中的节目；节目加载到末尾会继续滚动触发更多结果。打开视频后默认控制播放器。Shorts 中 ↓ 仍是下一条，搜索、确认和返回仍可用。

扩展弹窗右上角的「首页」按钮会在当前标签页打开对应网站的首页（YouTube、抖音精选、B站或优酷）。遥控器的首页键可在设置页录制；升级时保留已有按键配置，若默认首页快捷键已被占用，则首页保持未绑定，需自行录制。

### 抖音网页

支持 `https://www.douyin.com/jingxuan` 精选页和 `/video/…` 视频页：

- 方向键按瀑布流布局选择视频，选中项带蓝色光晕；到列表末尾继续按 ↓ 会滚动加载更多。
- 单击确认键在当前标签页打开选中的视频；等待时间与 YouTube 相同（默认 400 毫秒），用于区分双击。
- 视频页方向键左右快进／后退 5 秒，确认键播放／暂停，Esc 返回精选页；上下键不接管音量，单次 ↑↓ 滚动页面内容翻页。
- 视频页**双击 ↓** 进入右侧推荐卡片栏：方向键在右侧卡片间选择，确认键打开该视频，Esc 先退回播放器，再按一次才返回上一页。右侧栏尚未加载完时会等待几秒并自动定位。
- 抖音自己的**左侧导航**（精选、推荐、关注、朋友、我的、直播）可以直接用遥控器选择：在卡片行最左侧继续按 ←，或按左侧导航快捷键（默认 Alt+Shift+G）／指令面板的「左侧导航」，进入后 ↑↓ 选择、确认打开、→ 或 Esc 回到刚才的视频。导航项按网址识别，打开的是当前页面对应的那一项；下次进入会回到上次选择的导航项。
- 视频页的 ↑↓ 由扩展接管后再执行翻页，因此抖音自己的「↓ 切换下一条视频」快捷键不会在双击时抢先换片；双击间隔内第二次 ↓ 只用于进入卡片栏，页面不会滚动或换片。
- 只有 `/video/…`、`/note/…` 视频页会进入播放器模式。精选页里的大尺寸自动播放预览不会把页面切成播放器，方向键始终用于选择卡片。
- 返回后按 `data-aweme-id` 恢复上次选中的视频；抖音会在两次访问之间重排推荐，原视频不在列表时自动定位到相近位置。
- 视频页**双击确认键**打开指令面板，把播放器上没有独立按键的操作用同一套 ↑↓／确认／返回语法集中起来；面板打开时状态提示自动让位，返回键或 Esc 关闭。
- 视频页的浏览器全局模式改为**三击确认键**进入，双击留给指令面板；精选页仍然是双击 Enter。
- 首页键（Alt+Shift+H）在抖音页打开精选页。搜索框获得焦点时保留原生输入和方向键；登录、评论、分享等网页弹窗打开时同样保留原生按键。

#### 抖音播放页指令面板

面板沿用 YouTube 复合面板的玻璃外观和选择方式：↑↓ 移动高亮，确认键执行并关闭，返回键关闭；只列出当前页面实际存在的控件。右侧栏选片时（双击 ↓ 之后）不打开面板，确认键仍用于打开选中的推荐视频。

按 ← 或 → 开始输入组合键后，面板进入筛选模式：每按一键只保留「最左匹配」——按键序列以已输入内容开头的指令。例如 → 后剩 10 项，再按 ↑ 剩 4 项；输入完整组合立即执行。前缀存在时 ↑↓ 继续输入组合而不再移动列表，Backspace 撤销一步，清空后恢复 ↑↓ 选择。没有指令匹配时会重置并提示。组合键与 YouTube 的复合键分开保存，可在设置页单独录制。

| 分类 | 指令 | 说明 |
| --- | --- | --- |
| 播放 | 播放 / 暂停、后退 5 秒、前进 5 秒 | 直接控制 `<video>` |
| 播放 | 静音 / 取消静音 | 切换视频静音状态 |
| 播放 | 网页全屏 | 点击抖音播放器的网页全屏按钮 |
| 播放 | 全屏 | 浏览器原生全屏（与全屏快捷键一致） |
| 互动 | 点赞、收藏、分享 | 点击播放器对应按钮；分享会打开网页弹窗 |
| 互动 | 评论区 | 已展开时滚动到评论列表，否则点击评论按钮 |
| 互动 | 关注作者 | 仅在出现「关注」按钮时列出 |
| 选片 | 右侧推荐视频 | 进入右侧推荐栏，方向键继续选择 |
| 选片 | 上一条 / 下一条视频 | 合集或播放列表出现切换箭头时可用 |
| 选片 | 向上 / 向下翻页 | 滚动视频页自己的滚动容器 |
| 导航 | 搜索、左侧导航、抖音精选、返回上一页 | 与现有快捷键一致 |
| 导航 | 回到顶部 | 视频页滚动容器回到顶部 |

点赞、收藏、关注等会改变账号状态，使用前请确认当前视频。面板执行任意指令后立即关闭并回到播放器按键。

默认组合键如下，全部以 ← 或 → 开头，且没有一条是另一条的前缀：

| 分类 | 按键顺序 | 指令 |

### 哔哩哔哩 / 优酷网页

支持 `https://www.bilibili.com/` 首页与 `/video/BV…` 视频页，以及 `https://www.youku.com/ku/webhome` 首页和 `v.youku.com/v_show/…`、`v.youku.com/video?vid=…` 播放页。两个站点共用一套控制逻辑，但组合键分别保存。

- 首页方向键按行列选择卡片，选中项带蓝色光晕；B站拉到底部会继续加载新卡片，优酷则在当前可见的横向卡带内移动。
- 优酷首页的横向卡带共用一个裁剪容器，扩展只把完整落在屏幕内的卡片作为可选目标，且从不横向滚动页面，避免整页布局被推歪。
- 播放页 ↑↓ 调整音量：单次 ↓ 在双击间隔后降低音量，双击 ↓ 立即进入右侧推荐栏；↑ 立即提高音量。←→ 快进／后退 5 秒，单击确认播放／暂停。
- 右侧推荐栏中方向键选片、确认打开、Esc 返回播放器；B站右侧栏使用 `.video-page-card-small`，优酷使用右侧 `a.new-pic-text-item`。
- 播放页双击确认打开指令面板，双击留给指令面板；面板打开后约 1.2 秒内再按一次确认键，会收起面板并进入浏览器全局模式，快速连按三次确认同样生效。
- 返回首页后按 B站 BV 号或优酷 `vid` 恢复上次选择；列表重排时定位到相近位置。
- B站面板列出点赞、投币、收藏、分享和评论区；B站与优酷的播放器提供网页全屏、弹幕开关和下一集控件时，面板也会列出对应指令（优酷没有互动控件，因此互动分组不会显示）。面板执行互动指令会改变账号状态，使用前请确认当前视频。

## 复合键模式

双击确认键（默认 Enter）打开面板，有两种操作方式：

- **菜单选择**：↑↓ 选择指令，Return / Enter 或配置的确认键立即执行。选中项显示蓝色文字和玻璃高亮，高亮随选择平滑滑动；长按上下可连续移动，到边界停止。
- **快捷组合**：← / → 开始输入组合，之后方向键继续组合。每输入一步只保留仍能匹配的组合，并突出下一步；完整匹配后立即执行并退出。也可按确认键直接执行过滤后当前选中的指令。

入口跟随设置中的确认键，单击确认会等待双击间隔（默认 400 毫秒），双击不会先打开节目、提交搜索或切换播放。面板打开后约 1.2 秒内再按一次确认键，会收起面板并进入浏览器全局模式（见下文）；超过这个窗口，或在面板里按过其他键，确认键照旧执行选中指令。

面板和设置页都按「常用 → 播放器 → 页面」分类，常用操作排在最前面。菜单超出窗口时会随上下选择自动滚动，分类标题不会占用选择位置。

| 分类 | 按键顺序 | 指令 |

| 常用 | → → | 播放／暂停 |
| 常用 | → ← | 返回上一页 |
| 常用 | ← ← | 定位搜索框 |
| 常用 | → ↓ | 进入右侧列表 |
| 常用 | ← ↑ | 返回首页 |
| 常用 | ← → ↑ | 进入左侧导航 |
| 常用 | ← → ↓ | 展开 / 收起左侧导航 |

「展开 / 收起左侧导航」调用 YouTube 原生的导航按钮：迷你栏或收起状态按一次展开，再按一次收起；不改变当前操作区域和选中的节目。若正在左侧导航区域选择入口，收起时会顺带返回原区域；页面没有导航按钮或没有响应时，右下角会给出提示。Alt+Shift+N 与这条复合键效果相同，二者都可在设置页重新录制。

字幕、影院模式和播放器设置使用 YouTube 原生控件，当前视频没有字幕等情况会显示提示。影院模式先退出视频全屏，再切换页面布局；播放器设置打开后将焦点交给原生菜单，可继续用方向键、Enter 和 Esc 操作。静音只切换静音状态，保留原音量。

「画中画看评论」先退出视频全屏，向浏览器申请画中画，再滚动到评论区；评论区尚未加载时先滚到页面底部触发加载。视频在小窗继续播放，页面进入「评论区」区域：↑↓ 滚动约 40% 屏高，←→ 翻动约一屏，长按可连续滚动。「恢复正常播放」退出画中画、把页面滚回最顶部并回到播放器；在评论区按 Esc 或返回键效果相同，也可直接按 Alt+Shift+R。「回到页面顶部」只滚动页面，不改变画中画状态。

画中画使用浏览器原生能力，被禁用或当前视频不支持时会提示改用播放器自带的画中画按钮；点击画中画窗口会让它取得焦点，此时需先切回 YouTube 标签页再按键。

开始输入组合前，↑↓ 只移动菜单选择；输入开始后方向键只用于组合，长按不累计。Esc 或配置的返回键立即退出，Backspace 撤销一步，撤销到空序列后恢复上下选择；输错后提示并重置为完整列表。退出保留原操作区域、节目选框、左侧导航选项和搜索文字。面板也能显示在视频全屏中，不受普通状态提示开关影响，不设置空闲超时；系统启用减少动态效果时取消滑动动画。

设置页的「复合键模式」可以依次录制 2–4 步，新录制组合以 ← 或 → 开头；点击「完成序列」结束，录满 4 步自动结束。清空只禁用按键组合，仍可通过菜单选择执行，至少保留一条组合。重复序列或前缀冲突会阻止保存，例如不能同时设置 `← ↓` 和 `← ↓ ↑`。Enter 和确认键用于执行选中项，Esc、返回键及 Backspace 保留作退出与撤销。抖音播放页的组合键在下方「抖音播放页组合键」中单独录制，规则相同；两套组合分别对应不同页面，可以使用相同的按键序列。

升级时旧版默认组合自动替换为上表中的组合，保留已禁用的项目和其他遥控设置；已有自定义组合整组保留，新增组合与其冲突时保持未绑定，可在设置页重新录制。以 ↑↓ 或确认键开头的历史自定义组合可以通过菜单选择执行，重新录制时使用 ← / → 开头。

等待单击确认期间，其他按键操作会取消待执行的确认。页面跳转、窗口失焦、设置变更及关闭接管会取消模式；评论输入、输入法及网页弹窗保留原行为。关闭／刷新仅操作发出指令的 YouTube 标签页，不影响其他标签页。

## 浏览器全局模式

普通网页双击入口键（默认 Enter）进入，YouTube 页内和抖音视频页三击；这两处的双击仍打开各自的面板，面板打开后约 1.2 秒内再按一次确认键也会进入。入口跟随设置，可重新录制。仅需方向键、确认和返回键，不依赖额外键盘快捷键。

| 状态 | 方向键 | 确认 | 返回 |
| --- | --- | --- | --- |
| 直控 | ↑↓ 切换可控标签；←→ 后退／前进 | 打开菜单，不刷新 | 退出模式 |
| 菜单 | ←→ 切换「常用／网站／标签／页面」；↑↓ 选择 | 执行 | 返回直控 |
| 网页焦点 | ↑← 上一个、↓→ 下一个焦点 | 激活；文本框进入输入 | 返回直控 |
| 滚动 | ↑↓ 小步滚动，←→ 前／后翻屏 | 返回菜单 | 返回直控 |
| 输入框选择 | ↑← 上一个、↓→ 下一个 | 全选文字并进入原生输入 | 返回菜单 |
| 原生输入 | 交给网页编辑 | 网页自行决定提交或换行 | 返回输入框选择，保留文字 |
| 谷歌搜索 | 交给输入框移动光标 | 用当前关键词搜索，空关键词不跳转 | 返回菜单 |

菜单每次打开从常用组开始。常用组有「返回上个标签」、「谷歌搜索」、滚动、输入框、网页焦点和恢复上次关闭；返回上个标签按本窗口真实激活顺序选择最近可控标签，可在两个标签之间往返。页面组提供滚动、顶部、底部、刷新和关闭；关闭须再次确认，切换目标、导航或其他操作会取消确认。标签组按标题选择可控标签。无历史、无输入框或操作失败时显示提示。

网站组最多保存 8 个常用网站；可收藏当前网页，也可在设置页增删、编辑、排序并单独保存。仅支持不带用户名和密码的 HTTP(S) 地址，按规范化 URL 去重，查询参数和 hash 保留。打开时优先复用同窗口相同地址的标签，否则新建；普通网站需全站授权。设置页编辑期间若其他位置更新收藏，请重新加载后再编辑，避免覆盖。打开的网页列表也会在标题前显示该页面的图标，读取不到时不显示也不占位。每个收藏前显示网页图标：收藏当前网页时记录该页的 favicon，否则使用站点的 /favicon.ico；加载失败或被页面策略拦截时显示名称首字母。图标仅由浏览器按需加载，不新增权限，扩展不读取浏览器书签或全局历史。

滚动优先使用焦点所在的可滚动祖先，否则滚动页面；↑↓ 约为视区的 20%，←→ 约为 80%。输入框选择只聚焦并高亮，确认后才全选；语音文字由遥控器或系统输入，扩展不申请麦克风权限。焦点、滚动和输入只处理顶层页面，不遍历跨源 iframe 或封闭 Shadow DOM。

### 谷歌搜索

常用组的「谷歌搜索」在 HUD 里打开一个输入框，遥控器或系统语音输入的文字直接进入这个框，不会和网页抢焦点；确认键把关键词整理成单行空格后打开 `google.com/search`，空关键词或超过 200 字会留在原处并提示。返回键回到菜单，不会退出模式。

在谷歌搜索结果页（`google.com/search`、`google.com.hk/search`）另有一套静态启用的筛选手势：**双击 →** 开始筛选，↑↓ 在自然结果之间移动并高亮，←→ 翻到上一页／下一页（新页面自动选中第一条结果，筛选保持开启），确认键打开选中的结果，Esc 取消筛选。没有开始筛选时方向键仍是谷歌自己的滚动，单击 → 也不会滚动页面或移动光标，确认键不会打开任何结果，所以页面原有操作不受影响。结果只取自然搜索结果：广告、右侧知识面板和「大家还在搜」等谷歌自身链接不会进入筛选；`/url?q=` 跳转链接会还原成真实网址。翻页走的是页面自己的「下一页」链接，没有下一页时提示已是最后一页。Alt+Shift+S 定位到谷歌自己的搜索框。搜索结果页的浏览器模式仍按双击进入（不是播放页，不需要三击）。

### 恢复与权限

YouTube 无需额外授权。其他网站需在弹窗或设置页授权 `http://*/*` 和 `https://*/*`；撤权或关闭接管会退出模式。地址栏、浏览器内部页、应用商店、其他扩展页面和部分 PDF 查看器无法接收按键，也会从普通标签切换中跳过。模式宿主导航到不可控页面时，扩展优先转移到同窗口可控网页；没有候选时使用本地恢复页，可用遥控器选择常用网站、YouTube、恢复上次关闭或退出。恢复页不依赖外站脚本或网络显示；关闭窗口最后一个标签前也会先准备恢复页。手动关闭整个窗口不会被拦截或重开。

「恢复上次关闭」仅记录本扩展成功关闭的 HTTP(S) 页面，每个窗口最多保存最近 5 条 URL 和标题，恢复时新建网页；不恢复表单、滚动或播放进度，也不恢复鼠标关闭的标签或完整浏览器会话。记录保存在会话存储中，不跨浏览器重启保留。

用鼠标手动打开设置页等受限页面不会被强制切走。焦点若进入地址栏或操作系统界面，扩展无法全局接收遥控器按键；可切回网页或通过弹窗／设置页退出。普通网页焦点在链接、按钮或输入框时入口键保持原生作用；先将焦点移出这些元素再进入。

## Windows 软件快捷键（可选本机助手）

浏览器扩展无法向其他程序发送按键，因此这一功能需要项目自带的 `native/RemoteKeysBridge.ps1`。它读取设置页导出的 `remote-keys.json`，安装系统级键盘钩子；只有当前台软件的进程名（可选窗口标题）匹配时，才拦截配置中的单个遥控按键，并用 `SendInput` 发送目标快捷键。未匹配的软件、未映射的按键以及带 Ctrl / Alt / Shift / Win 的组合都原样通过。助手只忽略自己发出的按键；遥控器接收器或配套软件通过 `SendInput` 模拟的按键仍会正常匹配。

1. 在设置页「Windows 软件快捷键」添加软件配置：填写进程名（任务管理器 →「详细信息」中的名称，如 `PotPlayerMini64.exe`、`POWERPNT.EXE`、`wpp.exe`），可选填写窗口标题包含的文字。抖音电脑版可直接点「添加抖音电脑版」生成预设（确认→空格、Home→Z 点赞、PageUp/PageDown 上/下一条），再按客户端「快捷键设置」调整目标键。
2. 逐行录制遥控按键并设置目标快捷键；目标也可直接填写，如 `Ctrl+Shift+KeyS`、`AudioVolumeUp`、`F5`。
3. 保存映射后点击「下载 remote-keys.json」，把文件放进扩展目录的 `native/`，与脚本同目录。
4. 双击 `native/start-remote-keys.cmd`（保留调试窗口）或 `native/start-remote-keys-hidden.vbs`（隐藏窗口，只留托盘图标）。助手会在配置文件变化后约 1.5 秒自动重载。

托盘菜单可暂停 / 恢复映射、重新加载、打开配置和日志、退出。完整配置格式、支持的按键和限制见 [`native/README.md`](native/README.md)。安全提示：键盘钩子能看到系统按键，但助手不记录普通输入，日志只写已触发的映射；它不联网。不要为 Chrome 配置全局映射，否则会先于扩展吞掉遥控按键。映射到源键自身会被忽略。管理员权限窗口通常无法接收普通权限助手发送的按键；需要时以管理员身份运行助手。部分反作弊游戏会阻止模拟按键。

## 语音搜索与遥控器配置

先按搜索键，再按遥控器自身的语音键输入文字，最后按确认键搜索。返回键会清空本次输入并恢复之前的操作区域。扩展不识别语音，不申请麦克风权限。

设置页可录制单键或组合键；双击绑定只在播放器区域生效，避免干扰列表移动。Shorts 的双击单独分组，只在 Shorts 播放器和评论面板中识别；默认绑定为 → 展开评论、← 关闭评论、↑ 点赞。映射冲突会阻止保存。接管开关和映射保存后立即生效，可随时恢复默认。

若遥控器没有响应，打开设置页的「遥控器诊断」，切回 YouTube 操作，再回设置页查看收到的按键。诊断 5 分钟后自动停止，仅记录按键元数据与输入状态，输入文字的键值和 code 均会隐藏。被操作系统或浏览器截获的键不会传给网页，需在遥控器端换成其他键。

## 数据与实现

站点遥控在 `youtube.com`、`douyin.com`、`bilibili.com`、`youku.com` 和谷歌搜索结果页（`google.com/search`、`google.com.hk/search`）上静态启用；未授权全站访问时，浏览器全局模式只在 YouTube 与这些站点运行。授权后浏览器全局模式使用 `chrome.scripting` 动态注入普通网页，可随时撤销。`storage` 权限用于保存映射和常用网站；`tabs` 权限用于读取标签页标题与位置（切换、刷新、前进后退本身不需要它）。各标签页的最近 30 个页面位置及最多 60 条诊断记录保存在浏览器会话内，标签页关闭时清除；浏览器模式的会话状态同样只存在于会话存储，不跨浏览器重启保留。不联网发送这些数据。

- `remote.js`：按键标准化、映射校验、播放器双击识别、复合键前缀匹配和入口双击识别。
- `youtube.js`：卡片、搜索框、侧栏、评论区容器和视频／画中画按钮适配。
- `content.js`：区域状态、焦点、搜索、恢复、懒加载、画中画与评论区滚动、复合键面板。
- `douyin.js`：精选卡片、右侧推荐栏、播放器、滚动容器和 `data-e2e` 控件适配。
- `douyin-content.js`：抖音区域状态、选片、右侧栏、翻页与播放页指令面板的按键控制及组合键筛选。
- `bilibili.js`：B站首页卡片、视频页右侧推荐栏、播放器、搜索框、工具栏控件和评论区适配。
- `youku.js`：优酷首页横向卡带（只选完整可见卡片）、右侧推荐链接、播放器、搜索框适配。
- `video-site-content.js`：B站与优酷共用的区域状态、选片、音量／快进、右侧栏、播放页指令面板、组合键筛选和浏览器模式交接。
- `command-panel.js`：可复用的玻璃指令面板（分组、选择高亮、前缀筛选、滚动与执行回调），供抖音、B站和优酷播放页使用。
- `google.js`：谷歌搜索结果的自然结果卡片、真实网址还原、分页链接和搜索框适配。
- `google-content.js`：谷歌搜索结果页的筛选手势、↑↓ 选择、←→ 翻页、确认打开、Esc 取消和状态提示。
- `browser.js`：全局模式入口手势、模式内按键接管、HUD、操作列表渲染、网页焦点遍历、文字输入与谷歌搜索输入框，以及 YouTube／抖音／B站／优酷／谷歌页面的控制权交接。
- `background.js`：按标签页隔离会话恢复数据，关闭／刷新指定标签页，以及浏览器模式的会话状态、分组菜单选择和恢复页、页面动作下发和脚本注册。
- `native/RemoteKeysBridge.ps1`：Windows PowerShell 5.1 + 内嵌 C# 的键盘钩子、前台软件匹配和 `SendInput` 转发；不联网，独立于扩展运行。

YouTube 页面结构和浏览器媒体权限会影响兼容性；被网页弹窗挡住时优先关闭弹窗。全屏操作指视频全屏，不控制浏览器或操作系统全屏。

## 常见问题

- **更新后仍显示旧提示或旧面板**：在扩展管理页重新加载扩展，再刷新 YouTube 标签页；只刷新网页不会更新扩展文件。
- **双击 Return / Enter 没有打开面板**：确认已启用接管，并检查设置中的确认键；可适当增加双击间隔。输入法组合输入、评论框和网页弹窗会保留原生按键行为。
- **双击 Enter 没有进入浏览器模式**：在 YouTube 页内和抖音 / B站 / 优酷的播放页需要三击，两击会打开复合键／指令面板；面板打开后约 1.2 秒内再按一次确认键，或快速连按三次确认，都会进入。输入框、评论框和输入法组合输入中不会进入，避免吞掉文字输入；普通网页上焦点在链接或按钮时 Enter 也保持原生作用。若已在模式中，右下角 HUD 会显示当前标签页位置。
- **普通网页里按键没有反应**：浏览器全局模式需要 `http://*/*`、`https://*/*` 的可选授权。在弹窗点击「启用浏览器全局遥控」，授权后已经打开的页面会被补注入；仍无响应时刷新该页面。地址栏、`chrome://` 页面、应用商店和扩展页面不会收到按键。
- **想退出浏览器模式但页面不再响应按键**：点击工具栏弹窗的「退出浏览器模式」，或在设置页的「浏览器全局模式」中退出；模式也会在关闭窗口、撤销授权或关闭接管时自动结束。
- **网页焦点或输入框没有反应**：进入浏览器模式后按确认，在常用组选择「网页焦点模式」或「选择输入框」。只查找顶层页面可用元素；没有可用目标时会提示。输入状态按返回先回到输入框选择。
- **关闭标签页需要按两次**：在页面组选中关闭后，再次确认才关闭；移动选择、切换标签或导航会取消确认。
- **按返回后落到空白页**：模式会转到同窗口可控网页；没有候选时打开本地恢复页，使用方向键和确认键选择恢复操作。地址栏或系统界面取得焦点时扩展无法接收按键。
- **遥控器按键没有响应**：启用「遥控器诊断」查看网页实际收到的按键；系统或浏览器截获的按键需要在遥控器端重新映射。
- **没有字幕或影院模式**：相关功能取决于当前视频及播放器是否提供对应控件，不可用时扩展会显示提示。
- **画中画没有出现**：确认浏览器允许画中画且当前视频未受 DRM 限制；扩展先调用原生接口，失败时回退到播放器的画中画按钮。评论区未加载时会先滚动触发加载，仍不可用可稍后重试。
- **Shorts 双击没有反应**：确认当前是 Shorts 播放页且右下角提示列出对应双击操作。打开评论需要页面已经有评论按钮，按钮或面板加载较慢时会提示稍后重试；点赞仅在尚未点赞时执行。
- **Shorts 单击 ↑ / ← / → 变慢**：这是为了让双击有判断时间；等待双击间隔（默认 400 毫秒）后仍会执行原来的切换或快进。不需要双击时可在设置页清除对应绑定，恢复立即响应。
- **抖音页按键没有反应**：确认当前是 `douyin.com/jingxuan` 精选页或 `/video/…` 视频页，并在扩展重新加载后刷新页面。登录、评论、分享等网页弹窗打开时按键会保留给网页，先按 Esc 或关闭按钮退出弹窗；视频页双击确认键打开指令面板，浏览器全局模式需三击。精选页刷新后视频可能重新排序，扩展会定位到相近位置而不是原视频。
- **抖音指令面板没有出现或缺少某个功能**：确认当前是视频页（精选页没有该面板），并且不在右侧推荐栏中；双击要落在双击间隔内。面板只列出页面实际存在的控件，没有出现的点赞、收藏、上下一条等按钮说明当前页面未加载或没有该控件。
- **B站或优酷页面没有反应**：确认扩展已重新加载并刷新页面；首页需要视频卡片已经渲染，播放页需要播放器或右侧推荐栏已加载。优酷首页只选择完整落在屏幕内的卡片，横向卡带边缘的卡片要等页面自身滚动后才可选；优酷播放页的点赞、收藏、分享面板项只在页面提供对应控件时显示。
- **B站 / 优酷播放页 ↑↓ 没有调音量**：确认当前是视频页且播放器已就绪；单次 ↓ 要等过双击间隔（默认 400 毫秒）才降低音量，连续两次 ↓ 会改为进入右侧推荐栏。
- **左侧导航已收起**：按 Alt+Shift+N 或复合键 ← → ↓ 可直接展开，再按一次收起；也可先选择当前可见的迷你导航。没有可见入口时，扩展会尝试打开导航菜单，通过扩展打开的菜单会在按 → 或 Esc 返回时收起。
- **点过滚动条后遥控没反应**：新版 Chrome 会让页面、左侧导航或下拉面板的滚动容器自动获得焦点。扩展会立即把这类焦点交回页面，并且不把滚动容器误判为文字输入，方向键和确认键继续有效；搜索框、评论框等真实输入区域仍保留原生按键。
- **Windows 软件映射没有反应**：确认助手正在托盘运行、映射已启用、前台窗口的进程名匹配（任务管理器 →「详细信息」），并且助手与目标软件处于同一权限级别。目标软件若以管理员身份运行，需要以管理员身份启动助手。日志会列出匹配与转发结果，也可先运行 `-Validate` 检查配置。
- **映射后遥控键在其他软件失灵**：检查是否配置了进程名和标题都为空的全局配置；全局配置会匹配包括浏览器在内的所有前台窗口。删除全局配置，或为它填写进程名。

## 验证

开发与测试需要 Node.js 和 npm。以下命令在项目目录执行：

```sh
npm install
npx playwright install chromium
npm test
npm run test:e2e
```

浏览器测试在独立临时配置中**实际加载扩展**，用受控 YouTube 结构覆盖站内跳转、完整页面返回、跨标签页、延迟加载、语音文字输入、输入法、播放器、全屏以及画中画与评论区滚动，并验证三击进入浏览器全局模式（包括面板打开后稍晚到达的第三击）；Shorts 使用独立受控页面验证展开／关闭评论、评论滚动、点赞和延迟切换；抖音使用受控精选页和视频页验证方向键选片、大预览视频不会切到播放器、确认打开、返回后的选择恢复、双击 ↓ 进入右侧推荐栏后的选择与打开，以及双击确认键打开播放页指令面板后的选择、执行、静音与翻页；B站与优酷使用各自的受控页面验证首页选片、返回后的选择恢复、播放器音量、双击 ↓ 右侧栏、指令面板分组与真实控件（优酷只列存在控件）、组合键筛选与静音执行、弹幕开关、网页全屏与下一集，并确认播放页三击才进入浏览器模式；谷歌使用受控搜索结果页验证双击 → 才进入筛选、单击 → 不滚动也不开始、↑↓ 在自然结果间移动且不越过边界、←→ 翻页并在新页选中第一条、越界翻页留在原页、确认在双击间隔后或连按时打开、浏览器入口取消待执行确认、Esc 只取消筛选，以及浏览器模式输入框的输入、空关键词拦截和返回菜单；同时验证 ← / → 组合键的最左匹配筛选、Backspace 撤销、无匹配重置和完整组合立即执行。测试不会读取个人浏览器配置。

可选真实网站检查：`node scripts/live-smoke.cjs`。需要可访问 YouTube；未登录浏览器可能遇到登录验证，无法据此验证真实视频播放。已有兼容 Chromium 时，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向可执行文件。

本机助手可用 `powershell.exe -NoProfile -Sta -ExecutionPolicy Bypass -File native/RemoteKeysBridge.ps1 -Config native/remote-keys.example.json -Validate` 检查 JSON、按键名和内嵌 C# 编译；该命令不会安装钩子。

# YouTube 蓝牙遥控选片

Chrome / Edge Manifest V3 扩展。用蓝牙遥控器或键盘完成选片、语音文字搜索、播放和返回，无需构建。

## 安装或更新

1. 打开 `chrome://extensions` 或 `edge://extensions`，启用「开发者模式」。
2. 首次安装选择「加载已解压的扩展程序」并选择本目录；更新时点击扩展的重新加载按钮。
3. 刷新已打开的 YouTube 页面，确保旧版内容脚本已被替换。
4. 点击扩展图标 →「配置遥控器与按键诊断」，录制遥控器按键并保存。

## 默认操作

| 按键 | 操作 |
| --- | --- |
| 方向键 | 节目列表选片；播放器左右调整 5 秒、上下调整 5% 音量；搜索框保留编辑与建议选择 |
| Enter | 打开选中节目／播放暂停／提交搜索 |
| Esc | 清空并退出搜索；侧栏返回播放器；全屏先退出全屏；其他情况返回上一页 |
| Alt+Shift+H | 返回 YouTube 首页 |
| Alt+Shift+S | 定位搜索框，选中原文字供语音替换 |
| Alt+Shift+Y | 进入右侧节目列表，优先播放列表，没有则使用相关推荐 |
| Alt+Shift+P | 回到播放器控制 |
| Alt+Shift+K | 播放／暂停 |
| Alt+Shift+F | 切换视频全屏 |
| Alt+Shift+B | 直接返回上一页 |
| 播放器中双击 ↓ / ↑ | 进入右侧列表／搜索框 |

双击间隔默认 400 毫秒，可调整。第一次方向键立即执行，所以双击前可能改变一次音量；进入列表后连续方向键只移动选择。**2.0 起 Esc 改为单次逐层返回，Alt+Shift+Y 改为进入侧栏；回到播放器使用 Esc 或 Alt+Shift+P。**

页面右下角显示当前操作区域。返回列表时恢复此前选中的节目；节目加载到末尾会继续滚动触发更多结果。打开视频后默认控制播放器。Shorts 保留原有方向键切换，搜索、确认和返回仍可用。

扩展弹窗右上角的「首页」按钮会在当前标签页打开 YouTube 首页。遥控器的首页键可在设置页录制；升级时保留已有按键配置，若默认首页快捷键已被占用，则首页保持未绑定，需自行录制。

## 语音搜索与遥控器配置

先按搜索键，再按遥控器自身的语音键输入文字，最后按确认键搜索。返回键会清空本次输入并恢复之前的操作区域。扩展不识别语音，不申请麦克风权限。

设置页可录制单键或组合键；双击绑定只在播放器区域生效，避免干扰列表移动。映射冲突会阻止保存。接管开关和映射保存后立即生效，可随时恢复默认。

若遥控器没有响应，打开设置页的「遥控器诊断」，切回 YouTube 操作，再回设置页查看收到的按键。诊断 5 分钟后自动停止，仅记录按键元数据与输入状态，输入文字的键值和 code 均会隐藏。被操作系统或浏览器截获的键不会传给网页，需在遥控器端换成其他键。

## 数据与实现

仅在 `https://www.youtube.com/*` 运行。`storage` 权限用于保存映射；各标签页的最近 30 个页面位置及最多 60 条诊断记录保存在浏览器会话内，标签页关闭时清除。不联网发送这些数据。

- `remote.js`：按键标准化、映射校验和播放器双击识别。
- `youtube.js`：卡片、搜索框、侧栏和视频元素适配。
- `content.js`：区域状态、焦点、搜索、恢复和懒加载。
- `background.js`：按标签页隔离会话恢复数据。

YouTube 页面结构和浏览器媒体权限会影响兼容性；被网页弹窗挡住时优先关闭弹窗。全屏操作指视频全屏，不控制浏览器或操作系统全屏。

## 验证

```sh
npm install
npx playwright install chromium
npm test
npm run test:e2e
```

浏览器测试在独立临时配置中**实际加载扩展**，用受控 YouTube 结构覆盖站内跳转、完整页面返回、跨标签页、延迟加载、语音文字输入、输入法、播放器和全屏。测试不会读取个人浏览器配置。

可选真实网站检查：`node scripts/live-smoke.cjs`。需要可访问 YouTube；未登录浏览器可能遇到登录验证，无法据此验证真实视频播放。已有兼容 Chromium 时，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向可执行文件。

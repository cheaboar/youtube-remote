# YouTube 蓝牙遥控选片

Chrome / Edge Manifest V3 扩展。用蓝牙遥控器或键盘完成选片、语音文字搜索、播放和返回，无需构建。

项目仓库：[cheaboar/youtube-remote](https://github.com/cheaboar/youtube-remote)。

## 功能

- **方向键选片**：上下切换节目行，左右选择同一行的视频，蓝色光晕标出当前位置；滑到列表末尾时触发更多节目加载。
- **左侧导航**：首页节目行最左侧再按 ← 进入导航栏，↑↓ 选择首页、Shorts、订阅等入口，Return / Enter 打开，→ 或 Esc 回到原节目；支持展开栏和迷你栏，并可用 Alt+Shift+N 或复合键随时展开／收起。
- **复合面板**：双击 Return / Enter 打开，↑↓ 选择并确认执行，也可依次输入以 ← / → 开头的组合；指令按常用、播放器、页面分类。
- **浏览器全局模式**：双击 Enter 进入（YouTube 页内三击），↑↓ 立即切换标签页、Enter 刷新、←→ 后退／前进，Esc 退出；再次双击入口键可按标题跳转，无法接收遥控的标签页会被自动跳过。授权可选的全站权限后，在普通网页同样可用。
- **播放器控制**：播放暂停、静音、字幕、全屏、影院模式和原生播放器设置。
- **画中画看评论**：播放页一键开启系统画中画并定位到评论区，↑↓ 滚动评论、←→ 翻页；恢复键退出画中画并回到播放器顶部，另有「回到页面顶部」指令。
- **搜索与返回**：定位搜索框接收遥控器语音文字，逐层退出搜索、侧栏、全屏；从播放页返回后恢复节目选择。
- **Liquid Glass 界面**：磨砂透明面板、灰色文字、蓝色选中项和平滑滑动高亮；全屏时隐藏右下角提示，复合面板仍可打开。
- **遥控器配置**：录制单键、修饰键组合、双击和按键序列，支持冲突检查与按键诊断。

## 安装或更新

先在 GitHub 选择 **Code → Download ZIP** 并解压，或使用 Git 下载：

```sh
git clone https://github.com/cheaboar/youtube-remote.git
cd youtube-remote
```

1. 打开 `chrome://extensions` 或 `edge://extensions`，启用「开发者模式」。
2. 首次安装选择「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目目录。
3. 刷新已打开的 YouTube 页面，确保旧版内容脚本已被替换。
4. 点击扩展图标 →「配置遥控器与按键诊断」，录制遥控器按键并保存。

日常使用无需运行 `npm install` 或启动开发服务器。更新时下载最新代码覆盖原目录，或在项目目录执行 `git pull --ff-only`；然后在扩展管理页点击「重新加载」，再刷新 YouTube。已有按键配置会保留。

## 快速上手

1. 在 YouTube 首页或搜索结果中用方向键选片，单击 Return / Enter 打开节目。
2. 播放时双击 Return / Enter 调出复合面板，用 ↑↓ 选中所需功能，再按 Return / Enter 执行。
3. 选择「定位搜索框」后，使用遥控器的语音输入，再按确认键搜索。
4. 按 Esc 逐层返回；退出视频全屏后，右下角的操作提示会恢复。看评论时可在复合面板选「画中画看评论」，按 Alt+Shift+R 或复合键「恢复正常播放」回到播放器。
5. 在首页按 ← 移动到节目行最左侧，再按一次 ← 选择左侧导航；也可用 Alt+Shift+G 或复合面板中的「左侧导航」进入。按 Alt+Shift+N 或在复合面板中选择「展开 / 收起左侧导航」，可只切换导航栏的展开状态而不进入导航选择。
6. 双击 Enter 进入浏览器全局模式（YouTube 页内双击 Enter 仍是复合键面板，所以改成三击），用 ↑↓ 换标签页、Enter 刷新、←→ 后退／前进；Esc 退出。要在 YouTube 以外的网页使用，先在弹窗或设置页授权全站访问。

| Alt+Shift+R | 退出画中画看评论，恢复正常播放 |

双击间隔默认 400 毫秒，可调整。第一次方向键立即执行，所以双击前可能改变一次音量；进入列表后连续方向键只移动选择。**2.0 起 Esc 改为单次逐层返回，Alt+Shift+Y 改为进入侧栏；回到播放器使用 Esc 或 Alt+Shift+P。**画中画看评论后，Alt+Shift+R、Esc 或复合键「恢复正常播放」都会退出画中画并回到播放器。

macOS 键帽上的 Return 就是这里的 Enter；扩展兼容 `Return`、`Enter` 和小键盘 Enter，也会转换已录制的 Return 映射。

页面右下角显示当前操作区域，播放器提示「双击 Enter 调出复合面板」（跟随确认键配置）；视频全屏时隐藏右下角提示，退出全屏后恢复。返回列表时恢复此前选中的节目；节目加载到末尾会继续滚动触发更多结果。打开视频后默认控制播放器。Shorts 保留原有方向键切换，搜索、确认和返回仍可用。

扩展弹窗右上角的「首页」按钮会在当前标签页打开 YouTube 首页。遥控器的首页键可在设置页录制；升级时保留已有按键配置，若默认首页快捷键已被占用，则首页保持未绑定，需自行录制。

## 复合键模式

双击确认键（默认 Enter）打开面板，有两种操作方式：

- **菜单选择**：↑↓ 选择指令，Return / Enter 或配置的确认键立即执行。选中项显示蓝色文字和玻璃高亮，高亮随选择平滑滑动；长按上下可连续移动，到边界停止。
- **快捷组合**：← / → 开始输入组合，之后方向键继续组合。每输入一步只保留仍能匹配的组合，并突出下一步；完整匹配后立即执行并退出。也可按确认键直接执行过滤后当前选中的指令。

入口跟随设置中的确认键，单击确认会等待双击间隔（默认 400 毫秒），双击不会先打开节目、提交搜索或切换播放。在双击间隔内再按一次确认键，会收起面板并进入浏览器全局模式（见下文）；间隔之外的确认键照旧执行选中指令。

面板和设置页都按「常用 → 播放器 → 页面」分类，常用操作排在最前面。菜单超出窗口时会随上下选择自动滚动，分类标题不会占用选择位置。

| 分类 | 按键顺序 | 指令 |
| --- | --- | --- |
| 常用 | → → | 播放／暂停 |
| 常用 | → ← | 返回上一页 |
| 常用 | ← ← | 定位搜索框 |
| 常用 | → ↓ | 进入右侧列表 |
| 常用 | ← ↑ | 返回首页 |
| 常用 | ← → ↑ | 进入左侧导航 |
| 常用 | ← → ↓ | 展开 / 收起左侧导航 |
| 播放器 | ← ↓ ← | 静音／取消静音 |
| 播放器 | ← ↓ → | 开关字幕 |
| 播放器 | → ↑ | 切换视频全屏 |
| 播放器 | ← ↓ ↑ | 切换影院模式 |
| 播放器 | ← ↓ ↓ | 打开播放器设置 |
| 播放器 | ← → → ← | 画中画看评论 |
| 播放器 | ← → → ↑ | 恢复正常播放 |
| 页面 | ← → ← | 刷新当前页面 |
| 页面 | ← → → → | 关闭当前标签页 |
| 页面 | ← → → ↓ | 回到页面顶部 |

「展开 / 收起左侧导航」调用 YouTube 原生的导航按钮：迷你栏或收起状态按一次展开，再按一次收起；不改变当前操作区域和选中的节目。若正在左侧导航区域选择入口，收起时会顺带返回原区域；页面没有导航按钮或没有响应时，右下角会给出提示。Alt+Shift+N 与这条复合键效果相同，二者都可在设置页重新录制。

字幕、影院模式和播放器设置使用 YouTube 原生控件，当前视频没有字幕等情况会显示提示。影院模式先退出视频全屏，再切换页面布局；播放器设置打开后将焦点交给原生菜单，可继续用方向键、Enter 和 Esc 操作。静音只切换静音状态，保留原音量。

「画中画看评论」先退出视频全屏，向浏览器申请画中画，再滚动到评论区；评论区尚未加载时先滚到页面底部触发加载。视频在小窗继续播放，页面进入「评论区」区域：↑↓ 滚动约 40% 屏高，←→ 翻动约一屏，长按可连续滚动。「恢复正常播放」退出画中画、把页面滚回最顶部并回到播放器；在评论区按 Esc 或返回键效果相同，也可直接按 Alt+Shift+R。「回到页面顶部」只滚动页面，不改变画中画状态。

画中画使用浏览器原生能力，被禁用或当前视频不支持时会提示改用播放器自带的画中画按钮；点击画中画窗口会让它取得焦点，此时需先切回 YouTube 标签页再按键。

开始输入组合前，↑↓ 只移动菜单选择；输入开始后方向键只用于组合，长按不累计。Esc 或配置的返回键立即退出，Backspace 撤销一步，撤销到空序列后恢复上下选择；输错后提示并重置为完整列表。退出保留原操作区域、节目选框、左侧导航选项和搜索文字。面板也能显示在视频全屏中，不受普通状态提示开关影响，不设置空闲超时；系统启用减少动态效果时取消滑动动画。

设置页的「复合键模式」可以依次录制 2–4 步，新录制组合以 ← 或 → 开头；点击「完成序列」结束，录满 4 步自动结束。清空只禁用按键组合，仍可通过菜单选择执行，至少保留一条组合。重复序列或前缀冲突会阻止保存，例如不能同时设置 `← ↓` 和 `← ↓ ↑`。Enter 和确认键用于执行选中项，Esc、返回键及 Backspace 保留作退出与撤销。

升级时旧版默认组合自动替换为上表中的组合，保留已禁用的项目和其他遥控设置；已有自定义组合整组保留，新增组合与其冲突时保持未绑定，可在设置页重新录制。以 ↑↓ 或确认键开头的历史自定义组合可以通过菜单选择执行，重新录制时使用 ← / → 开头。

等待单击确认期间，其他按键操作会取消待执行的确认。页面跳转、窗口失焦、设置变更及关闭接管会取消模式；评论输入、输入法及网页弹窗保留原行为。关闭／刷新仅操作发出指令的 YouTube 标签页，不影响其他标签页。

## 浏览器全局模式

双击 Enter 进入，紧接着的按键立即生效，不再等待双击：

| 模式内按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 立即切换到当前窗口的上一个／下一个标签页，首尾循环；无法接收遥控的标签页会被跳过 |
| Enter / 确认键 | 刷新当前标签页 |
| ← / → | 当前标签页后退／前进（没有历史时提示并保持模式） |
| Esc / 返回键 | 退出浏览器模式 |
| 再次双击入口键 | 打开按标题选择标签页的列表 |

入口键默认是 Enter，与复合键的确认键相同，所以 **YouTube 页内需要三击**：双击 Enter 依旧打开复合键面板，第三击在双击间隔内按下时关闭面板并进入浏览器模式。其他网页双击 Enter 即进入。双击间隔之外的第三击照旧执行面板中的选中指令，不会误入模式。入口键可以在设置页重新录制，但 YouTube 内始终按三击计算，保持各页面一致。

因为下一次双击入口键用于打开标签列表，模式内单击 Enter 刷新会先等待一个双击间隔（默认 400 毫秒），确认没有第二击后才刷新；期间按其他键会放弃这次刷新。

标题列表中 ↑↓ 只移动高亮，Enter 跳转到选中标签页并回到直控状态，Esc 返回直控。列表和 ↑↓ 切换都只包含能接收遥控的标签页：YouTube，以及获得全站授权后的普通网页。地址栏、浏览器内部页（`chrome://`、`edge://`）、扩展页面、应用商店和本地文件会被直接跳过，不会跳过去后卡在无法接收按键的页面；窗口里只有一个可遥控标签页时，↑↓ 保持原位。标题以纯文本显示，Ctrl / Alt / Meta 组合键仍交给浏览器，普通文字不会被上报后台。模式没有空闲超时。

模式属于进入时的浏览器窗口：切到其他标签页继续生效，刷新、前进后退后自动恢复；切换窗口不会抢占焦点。窗口关闭时自动退出；进入模式的标签页关闭不影响模式，当前标签页会被重新认作操作对象。按住入口键不算连击，输入框和输入法保持原生按键。

### 全站权限

YouTube 页面无需额外授权。要在其他网页使用，点击扩展弹窗的「启用浏览器全局遥控」，或在设置页「浏览器全局模式」中授权 `http://*/*` 和 `https://*/*`。授权后新打开的页面自动生效；已打开的普通页面会立即补注入，个别无法注入的页面（如正在关闭、受限或尚未加载完成）刷新后即可接管。撤销权限或关闭接管开关会立即退出模式，残留脚本不再接受任何指令。

未授权时，↑↓ 和标题列表只在 YouTube 标签页之间切换，其他网站的标签页会被跳过；授权后这些标签页才会加入。

边界：地址栏、浏览器内部页（`chrome://`、`edge://`）、Chrome 应用商店、其他扩展页面和部分 PDF 查看器不会收到本模式的按键，↑↓ 切换和标题列表会自动跳过它们。手动点进这些页面时模式状态保留，但没有 HUD 和按键接管，切回普通网页即可继续，也可用弹窗按钮退出。扩展不捕获操作系统级按键，遥控器按键必须先由浏览器交给网页。

在普通网页上，焦点位于链接、按钮或输入框时 Enter 保持原生作用（打开链接、按下按钮、编辑文字），不会进入模式；先把焦点移出这些元素（点击页面空白或按 Tab）再双击。YouTube 页内由原遥控逻辑接管，不受此限制。

隐私：标签标题只下发给当前获得焦点的页面用于 HUD 显示，不写入会话存档、诊断记录，也不联网；列表内容在封闭的 Shadow DOM 中渲染，页面脚本无法读取。

## 语音搜索与遥控器配置

先按搜索键，再按遥控器自身的语音键输入文字，最后按确认键搜索。返回键会清空本次输入并恢复之前的操作区域。扩展不识别语音，不申请麦克风权限。

设置页可录制单键或组合键；双击绑定只在播放器区域生效，避免干扰列表移动。映射冲突会阻止保存。接管开关和映射保存后立即生效，可随时恢复默认。

若遥控器没有响应，打开设置页的「遥控器诊断」，切回 YouTube 操作，再回设置页查看收到的按键。诊断 5 分钟后自动停止，仅记录按键元数据与输入状态，输入文字的键值和 code 均会隐藏。被操作系统或浏览器截获的键不会传给网页，需在遥控器端换成其他键。

## 数据与实现

未授权全站访问时，YouTube 遥控只在 `https://www.youtube.com/*` 运行；授权后浏览器全局模式使用 `chrome.scripting` 动态注入普通网页，可随时撤销。`storage` 权限用于保存映射；`tabs` 权限用于读取标签页标题与位置（切换、刷新、前进后退本身不需要它）。各标签页的最近 30 个页面位置及最多 60 条诊断记录保存在浏览器会话内，标签页关闭时清除；浏览器模式的会话状态同样只存在于会话存储，不跨浏览器重启保留。不联网发送这些数据。

- `remote.js`：按键标准化、映射校验、播放器双击识别、复合键前缀匹配和入口双击识别。
- `youtube.js`：卡片、搜索框、侧栏、评论区容器和视频／画中画按钮适配。
- `content.js`：区域状态、焦点、搜索、恢复、懒加载、画中画与评论区滚动、复合键面板。
- `browser.js`：全局模式入口手势、模式内按键接管、HUD 与 YouTube 控制权的交接。
- `background.js`：按标签页隔离会话恢复数据，关闭／刷新指定标签页，以及浏览器模式的会话状态、标签页指令和脚本注册。

YouTube 页面结构和浏览器媒体权限会影响兼容性；被网页弹窗挡住时优先关闭弹窗。全屏操作指视频全屏，不控制浏览器或操作系统全屏。

## 常见问题

- **更新后仍显示旧提示或旧面板**：在扩展管理页重新加载扩展，再刷新 YouTube 标签页；只刷新网页不会更新扩展文件。
- **双击 Return / Enter 没有打开面板**：确认已启用接管，并检查设置中的确认键；可适当增加双击间隔。输入法组合输入、评论框和网页弹窗会保留原生按键行为。
- **双击 Enter 没有进入浏览器模式**：在 YouTube 页内需要三击，两击会打开复合键面板；两次按键要落在双击间隔内（默认 400 毫秒）。输入框、评论框和输入法组合输入中不会进入，避免吞掉文字输入；普通网页上焦点在链接或按钮时 Enter 也保持原生作用。若已在模式中，右下角 HUD 会显示当前标签页位置。
- **普通网页里按键没有反应**：浏览器全局模式需要 `http://*/*`、`https://*/*` 的可选授权。在弹窗点击「启用浏览器全局遥控」，授权后已经打开的页面会被补注入；仍无响应时刷新该页面。地址栏、`chrome://` 页面、应用商店和扩展页面不会收到按键。
- **想退出浏览器模式但页面不再响应按键**：点击工具栏弹窗的「退出浏览器模式」，或在设置页的「浏览器全局模式」中退出；模式也会在关闭窗口、撤销授权或关闭接管时自动结束。
- **遥控器按键没有响应**：启用「遥控器诊断」查看网页实际收到的按键；系统或浏览器截获的按键需要在遥控器端重新映射。
- **没有字幕或影院模式**：相关功能取决于当前视频及播放器是否提供对应控件，不可用时扩展会显示提示。
- **画中画没有出现**：确认浏览器允许画中画且当前视频未受 DRM 限制；扩展先调用原生接口，失败时回退到播放器的画中画按钮。评论区未加载时会先滚动触发加载，仍不可用可稍后重试。
- **左侧导航已收起**：按 Alt+Shift+N 或复合键 ← → ↓ 可直接展开，再按一次收起；也可先选择当前可见的迷你导航。没有可见入口时，扩展会尝试打开导航菜单，通过扩展打开的菜单会在按 → 或 Esc 返回时收起。
- **点过滚动条后遥控没反应**：新版 Chrome 会让页面、左侧导航或下拉面板的滚动容器自动获得焦点。扩展会立即把这类焦点交回页面，并且不把滚动容器误判为文字输入，方向键和确认键继续有效；搜索框、评论框等真实输入区域仍保留原生按键。

## 验证

开发与测试需要 Node.js 和 npm。以下命令在项目目录执行：

```sh
npm install
npx playwright install chromium
npm test
npm run test:e2e
```

浏览器测试在独立临时配置中**实际加载扩展**，用受控 YouTube 结构覆盖站内跳转、完整页面返回、跨标签页、延迟加载、语音文字输入、输入法、播放器、全屏以及画中画与评论区滚动。测试不会读取个人浏览器配置。

可选真实网站检查：`node scripts/live-smoke.cjs`。需要可访问 YouTube；未登录浏览器可能遇到登录验证，无法据此验证真实视频播放。已有兼容 Chromium 时，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向可执行文件。
